DR32 — Drum Rack 32

A clone of Ableton Move's Drum Rack, extended to 32 pads, for Schwung.

Work in progress. Usable but unreleased. Expect changes. Requires Schwung 1.2.0 or later — and 1.3.0 or later for the per-pad sends to reach anything.

What it is

DR32 loads Move's own .ablpreset drum kits and plays them through a reconstruction of the same Drum Sampler voice — so a kit built on the device opens here and sounds like itself, with twice the pads.

It is a Schwung sound generator: add it to a chain slot like any other instrument. It has no interface of its own; every page below is Schwung's own knob grid.

The pages

Jog moves between pages. On the Category page, click to go in, then click a row to open that category's kits.

Loading kits

DR32 opens empty. Kits live under Category, grouped by the library's own folders, plus everything you have made under My Kits.

The list is built by DR32 rather than by the file browser, and only real drum racks appear in it. Move's preset folder holds presets for every instrument — on a typical device, several hundred files of which only a fraction are drum kits — so a plain file browser would offer you a great many things that cannot load.

Scrolling the kit list loads what you land on. Move the cursor and the kit under it is loaded a moment after you stop, so you can hear your way through a category. There is no undo: the kit you were on is replaced. Save your work before browsing.

Pads

32 pads, notes 36–67. Hitting a pad selects it for editing while the transport is stopped; with a pattern running, the editor follows only on a host that reports live presses. The PAD knob (page 1, knob 1) selects a pad by hand, numbered 1–32.

Sample

SAMPLE opens a browser starting in the folder that pad's current sample came from. BROWSE steps through the neighbouring samples in that same folder, one per detent, so you can try alternatives without opening anything.

Shaping

Control
START / ENDplayback region, drawn over the waveform
TRSP / DETNtranspose in semitones, detune in cents

ATTACK / DECAY / HOLDthe amp envelope
ENVA-H-D or A-S-R
CUT / RES / TYPE / FILTERfilter, four types, with an on/off switch
VELVOLhow much velocity affects level
VOL / PANper-pad level and position
PUNCH / PTIMEMove's transient shaper; above zero it turns itself on
MASTERlevel for the whole kit — its own page, because it is not a pad control

Link

LINK sets one parameter across every pad at once. Click it on, turn a knob — every pad takes that value — and it releases as soon as you touch a different control, so the next knob is the focused pad's alone.

It never spreads the things that make a pad a distinct pad: its sample, its note, or the sample-browse position. It is off whenever DR32 loads.

Sends

Each pad has its own SEND A and SEND B amount, in dB, feeding Schwung's two global return buses. Put whatever effect you like on a return and every pad can tap it at its own level — one reverb shared by the kit rather than one inside each pad. A kit imported from Move brings its own send amounts with it.

Needs Schwung 1.3.0 or later. On an older host the knobs still turn and save, but nothing reads them, so they make no sound. DR32 has no internal effects of its own.

Saving

Your edits are stored in the Schwung set, on top of the kit that was loaded — so a set records which kit you used and what you changed about it. Kits themselves are Move's files and are not modified.

Known limits

  • Pads 17–32 are outside Move's 4×4 pad map, so the small map in the header does not light for them.
  • Per-pad playback effects other than Punch are parsed and preserved, so kits stay lossless and reopen correctly on Move, but they are not played back.
  • Return-chain effects saved inside a Move kit are preserved but not set up for you.
  • Browsing kits has no undo, as above.
